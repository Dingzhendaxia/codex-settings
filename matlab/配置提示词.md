# 给任意 Windows 电脑的 Codex 配置提示词

将下面内容复制给目标电脑上的 Codex。本提示词及配套模板不包含个人路径；执行时应在目标电脑动态确定路径。

---

请根据本目录 README.md 和以下仓库的 MATLAB 配置流程，为当前 Windows 电脑配置 Codex 与三个 MathWorks 组件：

https://github.com/Dingzhendaxia/codex-settings/tree/main/matlab

目标组件：

1. MATLAB Agentic Toolkit：MATK-2026.10.b。
2. MATLAB MCP Server：v0.15.0。
3. Simulink Agentic Toolkit：SATK-2026.10.c。

使用 Agentic Toolkit Installer v0.2.0。以上为参考固定版本，不代表最新版本。先核对官方兼容性；若不兼容、资产不可用或已有其他版本，不要静默升级、降级或混装，说明具体差异。

MATLAB、Simulink 和有效许可证是前提，不在这三个组件内。先检查本机是否已安装 Codex 和 MATLAB；未安装或未登录时说明所需步骤，不把组件安装当作 MATLAB 本体安装。

请执行以下完整流程：

1. 读取当前电脑的相关说明，定位实际 Codex 配置、MATLAB 根目录、MATLAB userpath 和生效 startup。优先从正常运行的 MATLAB 获取 matlabroot、userpath、which('startup','-all') 和 Simulink 信息。若 MATLAB 不在 PATH，可查询安装信息；有多个版本时确认目标版本，不随意选择。不得引用任何其他电脑的路径。
2. Codex 配置目录优先使用 CODEX_HOME，否则使用当前用户目录下的 .codex。技能目录使用当前用户目录下的 .agents/skills。工具包默认根目录使用 APPDATA 下的 MathWorks/Agentic Toolkits/v1。若使用自定义持久目录，后续安装、status、MCP、技能链接和 MATLAB 初始化必须一致。
3. 修改前备份已有文件。保留其他 MCP、技能、启动代码和当前用户工作，不覆盖整份配置，不关闭用户现有 MATLAB。
4. 仅从 MathWorks 官方仓库获取安装器和组件；检查来源、签名及 --help。使用 --non-interactive、--matlab-root、三个固定 --version、--skip-configure、--disable-telemetry 安装。遵守当前环境的网络、文件写入和执行审批要求。
5. 检查安装输出和 status，核实 server 可执行文件、两个 mltbx、toolkits 和 Simulink tools/tools.json。退出码为零不足以证明成功。检查两个 MATLAB 附加组件是否注册且启用；仅在需要时安装附加组件。正常 MATLAB 可用时不要因受限终端失败而直接判断许可证损坏。
6. 在实际 Codex config.toml 中仅添加或合并 [mcp_servers.matlab]，使用 existing 会话模式、Simulink extension-file、disable-telemetry=true、env_vars=['WINDIR']、startup_timeout_sec=120、tool_timeout_sec=600。生成的 TOML 必须包含当前电脑真实的绝对路径；不要把环境变量、占位符或 PowerShell 表达式直接写进 TOML，也不要重复服务段。existing 模式不同时添加 matlab-root、initial-working-folder、matlab-display-mode。
7. 仅注册 matlab-core 的 6 个和 model-based-design-core 的 11 个技能。优先创建指向持久工具包目录的目录联接，不能使用时复制。核验全部 17 个；已有同名技能先检查冲突，保留原文件，不以技能总数代替核验。
8. 将配套 startup.m 的自动初始化逻辑安装或合并到 MATLAB 实际生效的用户启动脚本。已有 startup 先备份并保留原逻辑；调用放在脚本执行区，本地函数放在函数区。不要修改安装目录 matlabrc.m，不改变工作目录。自定义工具包根目录时同步调整初始化路径。
9. 正常打开 MATLAB，执行初始化，检查 Installation Check 为 PASS、connector 正在运行。若需要用户手动打开 MATLAB或在 MATLAB 中执行修复脚本，给出目标电脑的真实命令。不要读取、显示、复制或提交 sessionDetails.json 中的会话凭据，不硬编码动态端口。
10. 验证 codex mcp get matlab；重新加载 Codex 配置，确认预期 14 个工具及 Simulink 扩展。通过原生 evaluate_matlab_code 实际执行版本、matlabroot、Simulink、startup 查询，并获取 which('simviewers.slx')。将返回的真实模型路径传给 model_overview，scope=root、detail=tree，检查工具错误和文本内业务错误。不要用文件存在或能列工具代替端到端验收。
11. 保存仅属于本次目标电脑的安装记录，列出版本、实际路径、备份、17 个技能核验、startup 检查和实际 MCP 调用结果。可公开的通用模板中不得包含这些个人路径或会话信息。

请在授权范围内完成工作。遇到审批、权限、许可或未启动 MATLAB 的阻碍时，完成不受影响的部分，准确说明尚未通过的验收项及最少所需操作。不要通过降低审批策略或绕过权限完成验收。只有实际 MATLAB 命令和 Simulink 模型读取均成功后，才能报告连接验收通过。

---

路径说明：通用文档可以不包含个人路径；目标电脑生成的有效配置仍需填写该电脑的真实绝对路径，二者并不冲突。
