# 新电脑 Codex + MATLAB / Simulink 工作流配置提示词

将下面代码块完整复制给新 Windows 电脑上的 Codex。提示词不包含个人电脑路径，执行时由目标电脑检测实际环境。

```text
请根据以下公开仓库，为当前 Windows 电脑配置完整的 Codex + MATLAB / Simulink 工作流：

https://github.com/Dingzhendaxia/codex-settings/tree/main/matlab

请先读取目录中的 README.md 和配套模板，再执行配置，不要仅提供操作建议。本文件就是执行提示词，无需递归读取自身。

目标：
正常打开 MATLAB 后，startup 自动初始化工具包并共享会话；Codex 通过 MATLAB MCP Server 连接该会话，可以执行 MATLAB 代码、读取和操作 Simulink 模型。

需要安装和配置的三个组件：
1. MATLAB Agentic Toolkit：MATK-2026.10.b
2. MATLAB MCP Server：v0.15.0
3. Simulink Agentic Toolkit：SATK-2026.10.c
使用 Agentic Toolkit Installer v0.2.0。

以上是仓库指定的固定版本，不代表最新版本。先检查本机兼容性；若版本不兼容、已有不同版本或下载资产不可用，说明差异，不要静默升级、降级或混装。

执行要求：

一、检测当前电脑
- 检查 Codex、MATLAB、Simulink 是否安装且可用，以及许可证情况。MATLAB 本体、Simulink 和有效许可证是前提，不包含在三个组件内。
- 自动定位 MATLAB 根目录、实际 userpath 和生效的 startup。
- 优先使用 MATLAB 返回的 matlabroot、userpath、which('startup','-all')。
- 若发现多个 MATLAB 版本且无法确定目标，再向我确认。
- 所有路径根据当前电脑检测，不能沿用仓库历史记录或其他电脑的路径。

二、安装三个组件
- 仅从 MathWorks 官方来源下载安装器和组件，检查来源、签名及 --help。
- 按仓库说明使用固定版本、--non-interactive、--matlab-root、--skip-configure 和 --disable-telemetry 参数。
- 工具包默认根目录使用 APPDATA 下的 MathWorks/Agentic Toolkits/v1；自定义根目录时保持安装、status、MCP、技能链接和初始化路径一致。
- 检查安装日志、status、可执行文件、两个 mltbx 和 Simulink 扩展文件，不能仅以退出码为零判断成功。
- 确认两个 MATLAB 附加组件已注册并启用，不重复安装已有且正确的组件。
- 正常 MATLAB 可用时，不要因受限终端失败而直接判断许可证损坏。

三、配置 Codex
- 优先使用 CODEX_HOME，否则使用当前用户的 .codex/config.toml。
- 修改前备份，只添加或合并 [mcp_servers.matlab]，保留其他配置，避免重复段。
- 使用 existing 会话模式，加载 Simulink tools.json，转发 WINDIR，设置 disable-telemetry=true。
- startup_timeout_sec=120，tool_timeout_sec=600。
- existing 模式不同时添加 matlab-root、initial-working-folder、matlab-display-mode。
- 最终配置写入当前电脑真实的绝对路径，不残留占位符或未展开的环境变量。
- 在当前用户的 .agents/skills 注册 matlab-core 和 model-based-design-core 两组共 17 个核心技能。优先使用指向持久目录的目录联接，必要时复制；逐一核验，已有同名技能先检查冲突。

四、配置 MATLAB 自动初始化
- 根据实际生效的 startup 安装或合并仓库中的初始化逻辑。
- 保留原启动代码，先备份；调用位于脚本执行区，本地函数位于函数区，不修改 MATLAB 安装目录中的 matlabrc.m。
- 不改变当前工作目录，不关闭用户已有 MATLAB 会话。
- 正常启动 MATLAB 后，应自动初始化并共享会话，Installation Check 为 PASS。
- 需要我在 MATLAB 中执行命令时，提供当前电脑可直接运行的真实命令。

五、实际验收
- 验证 codex mcp get matlab。
- 必要时提示我重启 Codex 或新建聊天以重新加载配置，随后继续验收。
- 核对预期 14 个 MCP 工具，包含 Simulink 扩展。
- 通过原生 evaluate_matlab_code 实际查询 MATLAB 版本、matlabroot、Simulink 和 startup。
- 获取 which('simviewers.slx') 返回的真实模型路径，再调用 model_overview，scope=root、detail=tree。
- 同时检查工具错误及返回文本中的业务错误。
- 不得用“文件存在”或“工具可见”代替实际连接成功。

请在授权范围内直接完成检测、安装、配置和验证，遵守环境的审批要求，不降低安全设置或绕过权限。不读取、输出或复制 sessionDetails.json 中的会话凭据，不固定动态端口，不把个人配置、日志或路径提交到公开仓库。

最后简洁报告：安装版本、配置与备份位置、17 个技能检查结果、自动初始化结果、MATLAB 和 Simulink 实际调用结果，以及任何尚未完成的项目。只有实际代码执行和模型读取均成功，才报告工作流配置完成。
```
